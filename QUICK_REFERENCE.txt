## 🔌 API Endpoints

### Calendar API - Filter Events
```bash
# All events
GET /api-calendar.php?action=getAll

# Filtered by status
GET /api-calendar.php?action=getFiltered&status=confirmed

# Filtered by date range
GET /api-calendar.php?action=getFiltered&startDate=2026-05-01&endDate=2026-05-31

# Search
GET /api-calendar.php?action=getFiltered&search=wedding

# Combined filters
GET /api-calendar.php?action=getFiltered&status=confirmed&startDate=2026-05-01&search=john
```

### Database Health API
```bash
# Check database status
GET /api-db-health-check.php

# Response includes:
# - Connection status
# - Table health (users, wardrobes, bookings, etc.)
# - Record counts
# - Database size
```

## 🛠️ How to Integrate

### Add Event Calendar to Navigation
```html
<a href="<?php echo BASE_URL; ?>/index.php?route=admin-calendar-events">
    <i class="fas fa-calendar-alt"></i> Event Calendar
</a>
```

### Add Health Widget to Dashboard
```php
<?php 
// At top of your admin page
if (!defined('VIEW_PATH')) {
    define('VIEW_PATH', dirname(__DIR__, 2) . '/views');
}
?>

<!-- In your page content -->
<?php include VIEW_PATH . '/admin/components/db-health-widget.php'; ?>
```

## 🆘 Troubleshooting

### Page not responsive
→ Clear cache (Ctrl+Shift+Delete), hard refresh (Ctrl+Shift+R)

### Buttons not showing on mobile
→ Check JavaScript is enabled, resize browser window

### Calendar filters slow
→ Reduce date range, use more specific search

### Health widget not appearing
→ Verify VIEW_PATH is defined, check include path

### Images not loading
→ Check api-wardrobe-image.php is accessible
